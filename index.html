DIAMOND TOP UP MM စည်းကမ်းချက်များ

၁။ ငွေသွင်းခြင်းအထောက်အထား မှန်ကန်မှုရှိခြင်း User များအနေဖြင့် ငွေသွင်းရာတွင် မိမိကိုယ်တိုင် အမှန်တကယ် လွှဲပြောင်းထားသော ပြေစာ (Screenshot) နှင့် မှန်ကန်သော ငွေသွင်းကုဒ် (Txn Code) နောက်ဆုံး ၆ လုံးကိုသာ တင်ရပါမည်။

၂။ မမှန်မကန် လုပ်ဆောင်မှုများအပေါ် အရေးယူခြင်း လိမ်လည်လိုစိတ်ဖြင့် ပြေစာအတုပြုလုပ်ခြင်း၊ သူတစ်ပါး၏ ပြေစာဟောင်းအား ထပ်မံအသုံးပြုခြင်း သို့မဟုတ် ကုဒ်အမှားများကို တမင်သက်သက် ထပ်ခါတလဲလဲ တင်ခြင်းများ ပြုလုပ်ပါက အဆိုပါ User အကောင့်အား မည်သည့်သတိပေးချက်မျှမရှိဘဲ အပြီးပိုင် ပိတ်ပင် (Ban) သွားမည်ဖြစ်သည်။

၃။ အော်ဒါကြာမြင့်ချိန်နှင့် အချိန်သတ်မှတ်ချက် ပုံမှန်အားဖြင့် အော်ဒါများကို ၁ နာရီအတွင်း အမြန်ဆုံး ဆောင်ရွက်ပေးပါသည်။ သို့သော် ဘဏ်စနစ် (KPay/WavePay) ဒေါင်းနေခြင်း၊ ကွန်ရက်လိုင်းမကောင်းခြင်း သို့မဟုတ် ဂိမ်းဆာဗာပိုင်း ပြဿနာများကြောင့် ကြန့်ကြာမှုရှိနိုင်ပြီး ထိုသို့ဖြစ်ပါက Admin ဘက်မှ အသေးစိတ် စစ်ဆေးပေးမည် ဖြစ်သည်။

၄။ မှာယူမှု ငြင်းပယ်ခံရခြင်း မိမိဘက်မှ ငွေမှန်ကန်စွာ လွှဲထားပါလျက် Order ငြင်းပယ်ခံရပါက (သို့မဟုတ်) နားလည်မှုလွဲမှားခြင်းများ ရှိခဲ့ပါက တရားဝင် Telegram Admin ထံသို့ အထောက်အထားအပြည့်အစုံဖြင့် လာရောက်ဖြေရှင်းနိုင်ပါသည်။
